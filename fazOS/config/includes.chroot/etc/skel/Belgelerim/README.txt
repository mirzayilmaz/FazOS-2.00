FazOS 1.0 - FEAS Software
=========================
Hos geldin, gece gorevlisi.
Bu sistem bir hayran yapimi (fan-made) simulasyondur.

Masaustundeki simgelere cift tikla:
 - NOTLAR  : .txt dosyalarini oku
 - TERMINAL: 'help' yaz
 - KAMERA  : Guvenlik kameralari
 - SAAT    : Vardiya saati

Not: Dosya icerikleri hikaye/teori ozetidir, resmi metin degildir.
